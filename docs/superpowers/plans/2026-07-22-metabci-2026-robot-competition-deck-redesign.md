> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce a verified, editable 17-slide copy of the supplied competition PPTX, preserving slides 1–2 and replacing slides 3–17 with the approved MetaBCIWebGame narrative.

**Architecture:** Use the supplied PPTX as the only visual template. Inspect every source slide, map each output slide to a duplicated source slide, edit inherited objects with `@oai/artifact-tool`, and export a distinct final PPTX. Keep all build artifacts in an external scratch workspace and write only the final deck to the repository `outputs` directory.

**Tech Stack:** JavaScript ES modules, `@oai/artifact-tool`, bundled presentation template-following scripts, Microsoft PowerPoint-compatible PPTX, bundled slide render and QA tools.

## Global Constraints

- Preserve source slides 1 and 2 without visible content changes.
- Keep exactly 17 slides in 16:9 format.
- Slides 3–17 must follow the six directory sections exactly: 项目概述、系统架构、解码方案、方法对比、实验结果、项目总结.
- Use the confirmed A visual route: white canvas, deep-navy active navigation tab, light-gray inactive navigation, flat diagrams and charts.
- Describe a real-time SSVEP-controlled maze game, not an entity robot, robot digital twin, or physical robot control system.
- Use only locally verifiable metrics and label fixed-window pseudo-online results separately from offline threshold-search records.
- Leave unverified hardware model and formal human-online metrics blank.
- Preserve the input PPTX and export a distinct edited copy.
- Use `@oai/artifact-tool`; do not use `python-pptx` or direct OOXML mutation.
- Fix every unintended overlap, clipping, wrapping, empty inherited placeholder, missing required logo, and stale depression-recognition reference before delivery.

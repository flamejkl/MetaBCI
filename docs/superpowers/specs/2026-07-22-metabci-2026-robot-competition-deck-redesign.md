# 2026 世界机器人大赛 MetaBCI 答辩 PPT 改稿设计

## 1. 改稿目标

在不改动原 PPT 前两页的前提下，重写第 3–17 页，使整套答辩围绕本地 `metabci_web` 项目的“基于 SSVEP 的网页脑控游戏平台”展开。

答辩面向综合型评委，时长为 8–12 分钟。叙事以真实体验为入口：用户注视网页中的上、下、左、右刺激块，系统实时采集和解码脑电，并控制迷宫游戏中的角色移动。

本稿不把迷宫角色描述为实体机器人、数字孪生或实体机器人控制成果。

## 2. 已确认的内容边界

- 保留第 1 页封面和第 2 页目录。
- 第 3–17 页全部重构，页数保持不变。
- 后续页面必须严格对应第 2 页的六个章节：项目概述、系统架构、解码方案、方法对比、实验结果、项目总结。
- 重点突出 Web 端闭环交互：网页刺激、在线解码、迷宫控制和实时反馈一体化。
- 现场演示定位为真人佩戴设备的实时脑控。
- 硬件品牌可写 Neuracle（博睿康）；代码无法唯一确认具体型号，因此型号字段留空。
- 无法从本地代码或结果文件复核的指标不填写，也不使用理论值冒充实测值。
- 指标必须区分离线评测、阈值搜索结果和真人在线表现，禁止混用。

## 3. 叙事方案

采用“体验驱动型”叙事：

1. 先解释用户如何通过注视控制迷宫角色。
2. 再拆解从网页刺激到游戏反馈的实时闭环。
3. 说明 SSVEP、脑电采集、FBTDCA 和动态停止的技术支撑。
4. 用方法对比突出 Web 化与低延迟决策的工程价值。
5. 用本地可复核结果说明当前性能，同时明确评测类型。
6. 以成果、限制和下一步工作收束。

### 第 3 页：项目背景及意义

- 传统脑机接口实验往往分散在刺激呈现、设备采集、在线解码和应用控制多个环节。
- 本项目将这些环节整合到可直接交互的网页脑控游戏中。
- 核心价值是降低应用展示门槛，并验证实时 SSVEP 控制链路。

主视觉：传统分散流程与 Web 闭环流程的简洁对照。

### 第 4 页：项目目标与使用体验

- 用户注视四方向视觉刺激块。
- 系统识别上、下、左、右意图。
- 解码指令驱动迷宫角色移动。
- 页面同步展示连接状态、方向结果和置信度等反馈。

主视觉：一张真实游戏界面图，叠加四步操作说明。

### 第 5 页：系统总体架构

展示五层闭环：

1. Web 刺激与迷宫交互层
2. 触发与同步层
3. Neuracle 脑电采集层
4. MetaBCI 信号处理与 FBTDCA 解码层
5. WebSocket 指令与反馈层

主视觉：可编辑的横向闭环架构图。

### 第 6 页：实时闭环数据流程

流程：方向刺激呈现 → 脑电采集 → 环形缓冲 → 时间窗截取 → 在线预测 → 方向指令 → 角色移动 → 状态反馈。

强调采集、解码和页面交互之间的异步通信关系。

### 第 9 页：脑电采集与预处理

- 设备：Neuracle 脑电放大器；具体型号留空。
- 采样率：250 Hz。
- 配置通道：14 通道。
- 重点使用枕区与顶枕区导联。
- 项目配置包含 8–30 Hz 滤波范围；展示时按“项目配置”表述。

主视觉：头皮通道示意与采集参数卡片。

### 第 10 页：FBTDCA 在线解码与动态停止

- 主算法：FBTDCA。
- 递增时间窗：125、250、375、500 个采样点，对应 0.5、1.0、1.5、2.0 秒模型。
- 从 0.5 秒开始检测，最长 2 秒强制输出。
- 使用最大分数和类别间隔双阈值判断是否提前停止。
- 当前配置阈值：类别间隔 0.35、最大分数 0.75、连续判定 1 次。

主视觉：从 0.5 秒到 2 秒的时间轴和提前停止判断流程。

### 第 11 页：传统桌面方案与 Web 闭环方案对比

对比维度：刺激呈现、应用集成、跨平台访问、交互反馈、部署方式。

对比只描述本项目已经实现的工程特征，不贬低特定第三方工具，也不声称未经验证的性能优势。

采用用户确认的 A 方案“白底技术叙事”：

- 中文字体优先使用微软雅黑或等价无衬线字体。
- 标题建议不小于 28 pt，正文不小于 16 pt；现场可读性优先于信息密度。
